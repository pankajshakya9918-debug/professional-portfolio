# Pankaj Shakya — Responsive Professional Portfolio

This project completes **Internship Task 1: Responsive Professional Portfolio**.

## Requirements covered

- Fully responsive personal portfolio
- HTML, CSS and JavaScript
- Hero section
- About section
- Skills section
- Projects section
- Education / Experience section
- Contact section
- Responsive navigation with mobile menu
- Smooth scrolling
- Interactive buttons
- Contact form validation
- Mobile-friendly layout
- Ready for GitHub
- Ready for deployment using GitHub Pages / Netlify / Vercel

## Files

- `index.html` — page structure and content
- `style.css` — responsive design and styling
- `script.js` — mobile menu, form validation and interactions

## Run locally

1. Download or clone the repository.
2. Open the folder in VS Code.
3. Open `index.html` in a browser.
4. For VS Code, you can use the Live Server extension.

## GitHub

```bash
git init
git add .
git commit -m "Create responsive professional portfolio"
git branch -M main
git remote add origin YOUR_GITHUB_REPOSITORY_URL
git push -u origin main
```

## GitHub Pages deployment

1. Push the files to a GitHub repository.
2. Open the repository.
3. Go to **Settings → Pages**.
4. Under Build and deployment, select **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save.
7. GitHub will provide the live portfolio URL.

## Important

The contact form performs client-side validation and then opens the visitor's email application using `mailto:`. It does not store messages on a server.
